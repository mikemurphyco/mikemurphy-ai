## 🗞️ AI News of The Week: Anthropic Prices Its IPO at $83

The company behind Claude is now on the stock market.

Anthropic priced its IPO at $83 a share, above its planned range of $70 to $78. It sold about 980 million shares, more than the 825 million it first planned, and raised $81.3 billion. That makes it one of the biggest IPOs ever.

The price values Anthropic at about $1.5 trillion. Shares trade on the Nasdaq under the ticker ANT, starting Thursday. Google, Microsoft, Nvidia, and AMD also agreed to invest a combined $26 billion at the IPO price.

- Anthropic now has a huge amount of cash to build and run future Claude models.
- You can now buy shares in the company that makes the AI tools you use.

## 🧠 AI Term of The Week: Evals

**Definition:**
An eval (short for evaluation) is a repeatable test that checks how well an AI system handles a task.

**Explain Like I'm 5:**
Evals are like practice quizzes that check if an AI is doing its job right.

**Real examples:**
- You ask an agent to find a fact in a document, then check that the answer is correct and comes from the right source.

## 🧰 AI Tool of The Week: T3 Code

![T3 Code homepage: "The open-source control plane for coding agents," with a Download for macOS button and agent logos around the headline](/assets/media/2026/11/issue-085-2.png)

**What is T3 Code:**
T3 Code is a free, open-source app that lets developers run their coding agents from one place instead of a terminal.

**What it does:**
- Runs Claude Code, Codex CLI, Cursor, OpenCode, and other agents in one interface.
- Uses the agent subscriptions you already pay for. It does not resell AI usage.
- Gives each agent task its own branch, then opens a GitHub pull request with one button.

**Why it's interesting:**
- You can check on your agents from your phone with the iOS and Android apps.

👉 [Explore T3 Code](https://t3.codes/)
