## The Web Design Show

*"To begin, begin."* — William Wordsworth

The steps taken to launch [PodcasterToolkit.co](http://podcastertoolkit.co) as a new WordPress site from ground zero:

### Step 1: Buy a Domain Name

Register something like podcastertoolkit.co at GoDaddy, roughly $8.99 for a new domain.

### Step 2: Sign Up for Web Hosting

[Bluehost](http://mikemurphy.co/bluehost) <!-- REVIEW: mikemurphy.co Pretty Link, deferred to the Pretty Links → Shlinks migration pass --> is the choice here, with an affiliate rate around $3.95/month; [HostGator](http://hostgator.com) is another commonly used option.

### Step 3: Buy a Premium Theme

[Elegant Themes](http://mikemurphy.co/divi) <!-- REVIEW: mikemurphy.co Pretty Link, deferred to the Pretty Links → Shlinks migration pass --> at $69/year is genuinely the only theme used — MikeMurphy.co runs on Divi, PodcasterToolkit.co runs on Extra (its magazine-style sibling). **Other podcast website options worth knowing:** [Appendipity Themes](https://www.appendipity.com/) and [PodcastWebsites.com](http://podcastwebsites.com).

### Step 4: Organize a Master Folder

Keep all assets, logos, and theme files in one place on the hard drive before starting.

### Step 5: Change Nameservers

Sign into Bluehost, assign the domain, and copy the nameservers (`ns1.bluehost.com` and `ns2.bluehost.com`). Sign into GoDaddy, delete the existing nameservers, and paste in the Bluehost ones. Propagation is quoted at 24 hours but usually only takes 5–10 minutes.

### Step 6: Install WordPress

Back in Bluehost, confirm the domain is verified, then run the one-click WordPress install. **Important:** choose the desired username at this step — it's difficult to change later in WordPress.

### Step 7: Sign In to the Site

Add `/wp-admin` after the domain (e.g., `yoursite.com/wp-admin`).

### Step 8: Install Divi or Extra

In WordPress, go to Appearance > Themes > Add New, and upload the theme's zip file from the master project folder created in Step 4.
