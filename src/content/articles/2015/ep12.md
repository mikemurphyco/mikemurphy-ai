## Ask Mike Anything: One Website or Two?

**Question (from Blab.im listeners):** Is a dedicated website needed for a podcast, separate from a personal/business page?

**Answer:** For most cases, keep it simple and use one website for everything. The only exception is when a podcast is so unrelated to the main website that combining them would confuse visitors — otherwise, keeping everything under one roof is easier for both host and audience.

## Web Tools Used for Mike Murphy Co.

### 1. Domain Names

[GoDaddy](http://godaddy.com) is the registrar of choice.

**Bonus tips:** the [Honey](https://www.joinhoney.com/) Chrome extension saves money automatically. For checking social media handle availability, [NameCheckr](https://www.namecheckr.com/) is extremely handy — it checks nearly every social platform at once for a given username. For finding the perfect domain name, [LeanDomainSearch](http://leandomainsearch.com) is a great resource — type in a desired name, and it shows availability plus tons of available alternatives.

### 2. Web Server

[Bluehost](https://www.mikemurphy.co/bluehost) <!-- REVIEW: mikemurphy.co Pretty Link, deferred to the Pretty Links → Shlinks migration pass -->, or [HostGator](http://hostgator.com).

### 3. Websites

[WordPress.org](http://wordpress.org) or [Squarespace](http://squarespace.com).

### 4. Themes

The Divi theme by [Elegant Themes](http://elegantthemes.com). **Child theme:** the Child Theme Configurator WordPress plugin.

### 5. Tools & Plugins

**WordPress plugin favorites:** Monarch (social media plugin), Bloom (email plugin), Click to Tweet, Blubrry PowerPress, and Pretty Link Lite.
